# D2PFX Launcher

Десктоп-лаунчер для модов Dota 2 с сайта [D2PFX](https://h6rd.github.io/Dota2PornFxWeb/).
Выбираешь моды, нажимаешь «Применить», и они уже в игре.

## Возможности
- Все категории и моды с сайта D2PFX, с превью и поиском
- Установка в один клик: мод скачивается сам
- Все выбранные моды собираются в один `pak01_dir.vpk`, конфликты решает порядок в списке
- Кнопка «Удалить моды из Dota» возвращает игру в чистое состояние
- Тёмная тема, интерфейс на русском, английском и украинском языках
- Встроенный гайд по шагам

## Скачать
Готовый `D2PFX_Launcher.exe` лежит в разделе **[Releases](../../releases)**.
Python ставить не нужно, достаточно запустить файл.

> Windows SmartScreen может предупредить, что программа не подписана.
> Нажмите «Подробнее» → «Выполнить в любом случае».

## Как пользоваться
1. **⚙ Настройки** → **Найти**: лаунчер сам найдёт папку Dota 2.
2. Выберите моды и нажмите **＋** на карточке.
3. Нажмите **✔ Применить в Dota**.
4. Один раз добавьте в Steam параметры запуска: Dota 2 → Свойства → Параметры запуска → `-language english`.
5. Играйте.

## Сборка из исходников
Нужен Windows и [uv](https://docs.astral.sh/uv/) или Python 3.10+.
Запустите `build_exe.bat`, и в папке `dist` появится `D2PFX_Launcher.exe`.
Если установлен [Inno Setup 6](https://jrsoftware.org/isdl.php), скрипт соберёт ещё и установщик.

Без сборки: `python launcher.py` (для превью нужен `pip install pillow`).
